# 我座城

瀏覽器入面起一座城。地圖係香港本身：維多利亞港、香港島、九龍、新界，同大嶼山、南丫、長洲。可以起路、住宅、街舖、工業、休憩、電箱，再沿真站名鋪港鐵同巴士。免費，唔使登入，進度記喺呢部機。

**呢個係原創遊戲。** 淨係借用「等軸城市建造」呢個類型，畫面、地圖、音樂、介面都係自己寫、自己畫。
**唔係《香城模擬器》，同佢冇任何關係**，冇用佢嘅名、圖、地圖、音樂或者介面。

## 點玩

```bash
npm install && npm run dev
```

打開 [http://localhost:3000](http://localhost:3000)。

1. 封面撳 **開波**（有存檔就撳 **繼續**）。
2. 撳 **路**，再撳塊地。拖動可以睇四周，按鈕或者滾輪放大。手機兩指放大。
3. **電箱**貼住條路，電力先沿路送出去。
4. 起 **住宅**、**街舖**、**工業**、**休憩**。有電先會起高，人多咗庫房先有稅。
5. 撳 **港鐵**，揀路綫，再撳地圖上嘅光點起站。站名係廣東話。兩個站接通之後，附近住宅人多啲、起得快啲，庫房有車費。
6. 撳 **巴士**，喺同一條路上落幾個站。站駁到就有車費；兩邊岸都有站會再多一截過海錢。
7. 休憩或者鐵路附近嘅住宅起得快啲。
8. **拆** 會退返少少錢。**儲低** 或者放低都會記喺呢部機（`localStorage`）。舊嘅方格地圖存檔唔會載入，要開新城。
9. 想一路起，撳 **連續** 再拖；電腦可以按住 Shift 拖。鍵盤 `1`–`9` 揀工具，空白鍵暫停。

海岸線用 Natural Earth 公開數據簡化，再補返赤鱲角同長洲。路綫顏色同站牌係自己畫，唔係港鐵標誌。

日夜會自己轉，間中落雨。撳 **快** 可以睇快啲。

`npm run build` 會出 Vercel / Next.js 生產版本。遊戲唔使環境變數，亦唔使登入。
