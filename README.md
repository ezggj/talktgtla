# Talk tgt la

香港人一齊傾偈嘅大型聊天室。

## 設定步驟

### 1. 開 Supabase（免費）
1. 去 https://supabase.com 註冊
2. 開一個新 Project
3. 去 SQL Editor 執行以下 SQL：

```sql
create table messages (
  id bigint generated by default as identity primary key,
  username text not null,
  content text not null,
  created_at timestamptz default now(),
  reply_to bigint references messages(id) on delete set null
);

alter table messages enable row level security;

create policy "Anyone can read messages" on messages for select using (true);
create policy "Anyone can insert messages" on messages for insert with check (true);
```

4. 去 Settings → API，複製：
   - Project URL
   - anon public key

### 2. 設定環境變數
喺專案根目錄建立 `.env.local`：

```
NEXT_PUBLIC_SUPABASE_URL=你的_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=你的_anon_key
```

### 3. 部署到 Vercel（免費）
1. 將成個 folder 上傳到 GitHub（開新 repo）
2. 去 https://vercel.com 用 GitHub 登入
3. Import 呢個 repo
4. 加環境變數（同上）
5. Deploy

### 4. 連接 Domain
喺 Vercel 設定加你嘅 talktgtla.com domain。

完成後就有一個完全自己控制嘅聊天網站。

### 5. 管理員（刪除訊息）
喺 Vercel Environment Variables 加（加密／唔公開）：

- `ADMIN_PASSWORD` — 管理員登入密碼
- `ADMIN_DELETE_TOKEN` — 伺服器刪除用 token（要同 Supabase `private.admin_config` 入面 `delete_token` 一致）
- `ADMIN_SESSION_SECRET` — 簽署 admin cookie 用

網站右上角撳「管理」輸入密碼。刪除經 `/api/admin/messages`，一般用戶嘅 anon key **冇** DELETE RLS policy，唔可以自己刪。

SQL（已套用可跳過）：`admin_delete_message` SECURITY DEFINER RPC + `private.admin_config`。
