# 我座城

瀏覽器入面起一座城。地圖係香港本身：維多利亞港、香港島、九龍、新界，同大嶼山、南丫、長洲。可以起路、住宅、街舖、工業、休憩、電箱，再沿真站名鋪港鐵同巴士。免費，唔使登入，進度記喺呢部機。

**呢個係原創遊戲。** 淨係借用「等軸城市建造」呢個類型，畫面、地圖、音樂、介面都係自己寫、自己畫。
**唔係《香城模擬器》，同佢冇任何關係**，冇用佢嘅名、圖、地圖、音樂或者介面。

## 點玩

```bash
npm install && npm run dev
```

打開 [http://localhost:3000](http://localhost:3000)。

1. 封面撳 **開波**（有存檔就撳 **繼續**）。開波對準已有街道，有街、樓、船同短程電車。一句提示講下一步，你起咗第一樣新嘢就收埋，跟住下面得一個下一目標。手機底欄有電車、路、住宅、街舖、拆，其餘喺 **更多**。縮細先見到成個海岸。側欄有城嘅花名同今日城事。暫停或者夜晚會話聽日點。
2. 每個地名得一句。中環、灣仔、銅鑼灣、尖沙咀唔會疊兩個名。港鐵站之間有段路，車會沿綫行。
3. 撳 **路**，再撳塊地。橙色係起得，紅色係起唔到，下面會講原因（海、郊野公園、未貼路、庫房唔夠）。
4. **電箱**貼住條路。未有電嘅樓頭頂有紅點，指住會話你知停咗。
5. **住宅**要附近有工做（街舖或者工業）先會再高，再高要有 **休憩**。**街舖**要附近有人住。**工業**請到人先開工。
6. 撳 **港鐵** 起站。**巴士**落喺路上。**渡輪**撳碼頭，中環同尖沙咀係維港船，再開去南丫、長洲或者梅窩。**電車**沿港島北岸鋪。
7. 朝早同黃昏會塞。條路塞住會話你知；過海未接通就話「過海塞車」。港鐵、巴士、電車、渡輪疏到，庫房會順啲。指住條路就見到原因。
8. 人、巴士、電車、港鐵、渡輪會喺你起嘅路同航線上面行。朝早多啲人由九龍摸去港島。
9. 間中有短事件：新年舖頭旺、中秋人去公園、突然落大雨、爆水管、港鐵延誤。一句講完，過咗就收。風球照舊，八號蓋過其他事件。
10. 撳 **分享**。卡上面有你個城名、人口、第幾日，同而家幅地圖。可以儲低圖片；部機肯分享就直接分享，唔使登入。
11. 間中掛風球。一號落雨，三號離島船停，八號巴士、電車、渡輪都停，舖頭收埋。八號會過。
12. 人口過二百、開到離島船、電車去到銅鑼灣、捱過八號，會講一句。
13. **拆** 退返少少。進度記喺呢部機。舊方格存檔，同之前較密嘅香港存檔，都唔會載入。開波就係新嘅維港。

放大見到區名同站名。夜晚仍然睇得到地同路，窗同街燈會亮。拖動睇四周，按鈕或者滾輪放大。手機兩指放大。鍵盤 `1`–`9` 揀前面幾樣工具，空白鍵暫停。

海岸線用 Natural Earth 公開數據簡化，再補返赤鱲角同長洲。路綫顏色同站牌係自己畫，唔係港鐵標誌。

日夜會自己轉，間中落雨。撳 **快** 可以睇快啲。

`npm run build` 會出 Vercel / Next.js 生產版本。遊戲唔使環境變數，亦唔使登入。
